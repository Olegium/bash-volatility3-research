# volatility3-

Команда для анализа оперативной памяти 

python3 vol.py -f dump.mem windows.plugin

1. Информация о системе и процессах

windows.info: Общая информация (версия ОС, время загрузки, базовый адрес ядра). Аналог kdbgscan в V2.

windows.pslist: Список активных процессов (PID, PPID, имя, время создания).

windows.pstree: Дерево процессов (видно, кто кого породил). Идеально для поиска цепочек атак.

windows.psscan: Сканирование памяти на наличие "мертвых" или скрытых процессов (техника DKOM).

windows.cmdline: Показывает полную командную строку каждого процесса (где часто видны параметры вирусов).

2. Сетевой анализ

windows.netscan: Аналог netstat. Показывает все TCP/UDP соединения, порты, IP-адреса и PID владельца.

windows.netstat: Более детальный разбор сетевых стеков.

3. Файловая система и объекты
   
windows.filescan: Поиск всех файловых объектов в памяти (даже удаленных). Можно найти путь к вредоносному EXE.

windows.dumpfiles: Извлечение конкретных файлов из памяти по их пути или inode.

windows.dlllist: Список загруженных DLL для каждого процесса (поиск инъекций).

5. Вредоносная активность (Malware Hunting)

windows.malfind: Ищет признаки внедрения кода (RWX память, подписи PE-заголовков внутри чужих процессов). Главный инструмент против руткитов и инжекторов.

windows.hollowprocesses: Детект техники Process Hollowing (вирус убивает легитимный процесс и заселяет его своим кодом).

windows.suspicious_threads: Поиск потоков, работающих в подозрительной памяти.

6. Реестр и конфигурация

windows.registry.printkey: Чтение ключей реестра прямо из дампа (например, автозагрузка Run keys).

windows.amcache: Анализ артефактов совместимости приложений (что запускалось раньше).
